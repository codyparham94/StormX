# StormX
Utility Risk Storm Assessment Map

A map of past and forecast U.S. storms, scored for the risk of utility outages. It is built with the ArcGIS Maps SDK for JavaScript, hosted on GitHub Pages at [storms.codyparham.com](https://storms.codyparham.com), and reads its data from Cloudflare R2.

See [docs/PLAN.md](docs/PLAN.md) for the project plan.
